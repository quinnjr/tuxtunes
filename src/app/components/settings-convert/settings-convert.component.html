FLAC

Lossless. Compression level trades encoding time for file size only — every level decodes to bit-identical audio, so 12 is free quality-wise.

M4A

ALAC is lossless and plays everywhere an M4A does. AAC is smaller but discards audio; pick it only when size matters more than fidelity.
